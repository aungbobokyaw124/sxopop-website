# SXOPOP Intelligent Hub

Production-ready responsive landing website for SXOPOP, built with React + Vite + TailwindCSS + Framer Motion.

## Features
- Responsive desktop/mobile navigation
- Myanmar-first content with Noto Sans Myanmar
- Indigo/Sky brand system
- Animated hero dashboard visual
- Feature, template, pricing and payment sections
- Infinite partner slider
- Smooth scrolling and reduced-motion support
- No backend dependency for the landing page

## Run locally
```bash
npm install
npm run dev
```

## Production build
```bash
npm run build
npm run preview
```

## Environment
The landing page does not require Supabase credentials to render. Add them to `.env.local` when backend integrations are enabled.

## Stack
React 19 · Vite · TailwindCSS 3 · Framer Motion · Lucide React
